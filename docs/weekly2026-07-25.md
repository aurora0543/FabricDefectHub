# 本周工作汇报

## 工作简述

本周主要完成三个任务：

1. 适配了新模型（共计18个），把计划内的数据集补齐（共计9个），
2. 开销类指标的验证进行完善。
3. 重构各算法的调参接口。

## 代码部分

### 1. 新模型适配

本周新适配并跑通的模型有三个：

- **Dinomaly**
- **MoE-CLIP**
- **AnomalyCLIP**

这几个模型是基于源代码仓库移植移植，无直接调用的库。完成了后端训练、数据读取、评价指标的等部分的接入。

### 2. 调参接口补齐

之前接入模型时，只要关注能否复现，而忽略了原论文调参的需求。这周把这块补齐，每个模型都有自己独立的配置和默认参数表，原论文里的关键超参现在都能在 YAML 里直接改，命令行也支持时覆盖。

### 3. 数据集补齐

本周加进来的数据集：

- Fabric Defects Dataset
- 阿里天池布匹数据集
- SDUST-FDD
- TILDA Textile Texture Database
- AITEX
- VisA
- MVTec LOCO AD

其中，天池数据集基于YOLO格式标注，与当前任务场景的适配性有限，且原始数据预处理工作量较大，因此暂不纳入本次处理，后续将根据实际需求另行评估其使用方案。本周工作重点主要集中在对自有模型与数据集的链路重构上。

### 4. Bug修复

在实际接入数据集的过程中，发现原有程序存在缺陷：此前仅以单一示例配置跑通全流程，未考虑不同模型对数据格式及预处理方式的差异化需求。本周重点针对此问题进行了重构，按各模型要求分别独立实现DataLoader，涵盖切片、拼接、特定数据增强及归一化等操作，确保数据处理环节按需执行，不再共用统一流程。

### 5. 指标代码与验证

- **开销类指标**：已在代码层面完成计算类指标的实现，具备可运行与可验证性，主要包括：
  - 帧率波动：FPS时序标准差 / 变异系数
  - 吞吐量-分辨率衰减斜率及组间差：最小二乘拟合β值，辅以Bootstrap 95%置信区间
  - 硬实时预算内最大并发路数：单帧延迟≤33ms约束下
  - 跨域精度退化率及置信区间
  - 升级不一致率与阈值漂移
  - 显存占用：均值及峰值
  - 微小缺陷量化召回衰减：对照常规缺陷（<10px）

## 问题与思考

1. **开发链路的顺序问题**：这周最大的一个体会是，之后接新模型的链路应该是先让模型单独跑通，确认没问题了再考虑怎么移植到项目里，而不是像之前那样先往项目里移植、移植完了再来解决能不能跑的问题。
2. **移植工作量估计不足**：这次很多模型是从别人仓库搬过来的，不是能直接 import 的模块，实际开发量比预估的大。后面排期要把这部分成本算进去。
3. **退化率类指标的问题**：不同精度下的退化率无法直接套用，需针对具体模型的输出形式做适配；此外，部分模型本身不支持混合精度，该类模型的退化率指标适用性需后续再评估。
